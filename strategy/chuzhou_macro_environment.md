# 滁州宏观环境

# 草稿区我希望能够为市场上的从业者找到一些道路。嗯，因为我在深度调研市场的时候，看到大家普遍很无论是懂行的还是不懂行的，都看不到什么太大的希望。


同时我也看到政府在积极提供资源做公共服务，似乎是有希望的，但是没有整合起来。


其实说起来有一大堆的经济问题需要讨论。比如，市场到底有没有消费能力。我观察下来的结论是，平价的消费是比较受欢迎的，这个和收入结构有关，也和文化因素有关。因为滁州不是一个消费主义的城市，总体来讲，整个城市比较务实。


在这样的市场上，讲文化也不能是抽象的，而是务实又带着深度的。


我心目中更好的滁州是什么样的？

商业文化更加发达，消费更加多样有趣，更加像隔壁南京。


南京人为什么会来滁州？主要就是来琅琊山玩。
